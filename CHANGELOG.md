# Changelog

## 0.1.0 (2026-10-27)

First release: browse, search, filter and page a server's files from a
Summernote toolbar button; upload by button or drag-and-drop, one file at a
time; insert an image with alt text or any other file as a link. JSON protocol,
`url` or `list`/`uploadFile` functions, `params` and `headers`, translatable
strings, and a reference PHP backend.
